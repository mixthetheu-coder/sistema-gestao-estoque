# 📦 Sistema de Gestão de Estoque com Alertas via Telegram

SaaS compacto para controle de estoque de pequenos comércios com interface web responsiva (Flask) e integração com bot do Telegram para notificações diárias e alertas de estoque crítico em tempo real.

## 🚀 Funcionalidades

- **Painel Web Simples:** Cadastro, atualização e remoção de produtos em estoque via interface Flask.
- **Alertas Automáticos:** Notificação imediata no Telegram quando um item atinge o nível mínimo predefinido.
- **Relatório sob Demanda:** Disparo do status geral do estoque para o grupo/chat cadastrado com apenas um clique.
- **Persistência de Dados:** Banco de dados SQLite local, leve e sem necessidade de configurações complexas.

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- **Flask** (Microframework Web)
- **SQLite3** (Banco de dados relacional)
- **Telegram Bot API** (Webhook/HTTP Requests)
